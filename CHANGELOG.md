# История изменений

## 0.5.0

- Новый компактный интерфейс с боковой навигацией, общей сеткой, тёмной, светлой и системной темами.
- English, Русский, Беларуская и Українська; единые размеры текста, векторные иконки и DPI для каждого монитора.
- До вставки ссылки — подсказка, во время анализа — загрузочный макет. Параметры и кнопки появляются после анализа.
- Предпросмотр справа: чёткая обложка с сохранением пропорций и плавная размытая подложка из всего кадра. До восьми доступных кадров видео с интервалом три секунды; извлечение останавливается при скрытии окна.
- Качества определяются по конкретному источнику, без фиксированного потолка разрешения. MP3 320 по умолчанию; готовый MP3 меньшего битрейта не увеличивается искусственно.
- Выпадающая панель параметров с кнопкой «Применить»: для аудио только фрагмент, для видео также дорожка и субтитры. Панель не сдвигает кнопку скачивания.
- Ссылка и настройки остаются после скачивания. Повторная загрузка получает отдельное задание; завершённую запись можно снова выбрать и настроить.
- При отсутствии длительности или размера FFprobe асинхронно читает служебные данные прямого потока. Запрос ограничен по времени и отменяется при смене ссылки.
- Размер без готового значения оценивается по длительности и битрейту выбранных потоков; MP3 учитывает выбранный битрейт и фрагмент.
- Итоговый контейнер в карточке берётся из реального файла, без преждевременной надписи MP4.
- Стабилизирована анимация переключателя видео/аудио при быстрых кликах и изменениях геометрии.
- Очередь под кнопкой «Скачать»: собственный прогресс каждого файла, отмена, ожидание и автоматический запуск. По умолчанию три одновременные загрузки.
- Завершённые записи переходят в «Скачанные файлы» после всей обработки. Доступны открытие файла и показ в папке.
- Пакет ссылок и выбранные элементы плейлиста запускаются автоматически. Формат каждой задачи фиксируется при добавлении.
- Читаемые имена файлов; совпадения нумеруются, пути для докачивания сохраняются. Название, заданное автором, не изменяется.
- Настройки папки, поведения при закрытии, музыкальных тегов и обложек, имён и подпапок. Поле папки ограничено 440 px; перед скачиванием — отступ 20 px.
- Страница «О программе» с описанием, версией, ресурсами и авторством у нижнего края.
- Запуск развёрнутым и восстановление состояния окна из трея. Проверочный запуск сборки использует отдельный временный профиль.

## 0.4.0

- Приложение переименовано в **AL Media**; полное название — **AnyLoad Media**.
- Новая эмблема используется в интерфейсе, EXE, установщике и ярлыках Windows.
- Добавлены сведения о продукте и единая идентификация на панели задач Windows.
- Python-пакет переименован в `al_media`, сборки — в `ALMedia`.
- Сохранена совместимость с профилем и установкой предыдущих версий.
- В сборку входят только рабочие ресурсы; пробные иконки исключены.
- README и документация обновлены для публикации на GitHub.

## 0.3.0

- Загрузка запускается сразу кнопкой «Скачать» или Enter.
- Выбор разрешения и аудиоформата доступен через «Качество…».
- Настройки сокращены до папки загрузки, темы и языка.
- Убраны обращение к браузерному профилю, cookies и автоматические обновления.
- Добавлена защита очереди от одновременного запуска нескольких экземпляров.
