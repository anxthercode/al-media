## Возможности

- **Скачивание по ссылке** — кнопка «Скачать» или Enter сразу запускает загрузку.
- **Лучшее доступное качество** — видео и звук выбираются автоматически.
- **Понятный выбор разрешения** — через «Качество…»: 1080p, 720p и другие варианты, доступные у конкретного видео.
- **Аудио отдельно** — исходный аудиоформат или MP3 с битрейтом 128, 192 и 320 кбит/с.
- **Несколько загрузок** — очередь, параллельная обработка, прогресс, скорость и оставшееся время.
- **Добавление списком** — несколько ссылок с новой строки, импорт `.txt` и перетаскивание в окно.
- **История** — поиск скачанных файлов, открытие видео и переход в его папку.
- **Светлая и тёмная темы**, русский, английский и украинский интерфейс.
- **Инструменты в комплекте** — yt-dlp, FFmpeg/FFprobe и Deno. Для готовой сборки отдельно устанавливать Python не нужно.

Поддержка сайтов обеспечивается [yt-dlp](https://github.com/yt-dlp/yt-dlp): YouTube, Vimeo, VK, TikTok и другие площадки, для которых работает соответствующий обработчик. Доступность зависит от сайта, конкретного материала и подключения.

## Установка

Готовые сборки распространяются через раздел **Releases** этого репозитория.

| Файл | Назначение |
|---|---|
| `ALMedia-<версия>-Setup-win-x64.exe` | Установить приложение для текущего пользователя |
| `ALMedia-<версия>-portable-win-x64.zip` | Запустить без установщика после полной распаковки архива |
| `SHA256SUMS.txt` | Контрольные суммы файлов выпуска |

**Требования:** Windows 10 или 11, 64-разрядная система, интернет и свободное место для загружаемых файлов.

В portable-папке запускайте `ALMedia.exe`. Сохраняйте рядом с ним все поставляемые папки — в них находятся компоненты приложения.

Новую версию можно установить поверх предыдущей. Удалить приложение можно через **Параметры Windows → Приложения → AL Media**. Скачанные файлы при удалении программы сохраняются.

## Использование

1. Скопируйте ссылку на видео и вставьте её в поле вверху окна.
2. Нажмите **Скачать** или Enter.
3. После завершения нажмите **Открыть файл** или **Показать в папке**.

По умолчанию используется папка Windows «Загрузки». Её можно изменить в **Настройках**.

### Другое качество или только аудио

Вставьте ссылку и нажмите **Качество…**. После получения информации выберите видео нужного разрешения, исходное аудио или MP3, затем нажмите **Начать**.

Список разрешений формируется по доступным форматам ролика. Приложение не превращает исходное 720p-видео в 1080p. Битрейт MP3 задаёт параметры конвертации и не улучшает исходную запись.

### Несколько ссылок

Вставьте ссылки с новой строки или выберите **Из файла .txt**. Ссылки и текстовые файлы также можно перетащить в окно. Загрузки добавляются в очередь; повторно вставленные в одном списке одинаковые ссылки пропускаются.

## Если видео не скачивается

AL Media работает с общедоступными материалами без входа в браузер и не читает браузерные cookies. Автоматических проверок обновлений нет.

- **HTTP 429 / проверка на бота:** сайт ограничил запросы с текущего подключения. Попробуйте позже или через другую сеть.
- **Видео требует входа, закрыто или недоступно в регионе:** приложение не обходит эти ограничения.
- **Ссылка не поддерживается:** проверьте ссылку и наличие поддержки площадки в yt-dlp. Изменения на сайте могут временно нарушить загрузку.
- **Не найдены компоненты:** распакуйте portable-архив целиком или переустановите приложение из полного установщика.

Технические журналы доступны через **О программе → Открыть папку логов**. Переустановка сама по себе не снимает ограничения сайта.

## Разработка

Для запуска из исходников и сборки нужны **Windows x64, Python 3.12 и PowerShell**. Команды выполняются из корня клонированного репозитория.

```powershell
# Создать окружение и установить закреплённые зависимости
./scripts/bootstrap.ps1

# Получить yt-dlp, FFmpeg/FFprobe и Deno с проверкой SHA-256
./scripts/fetch-tools.ps1

# Запустить приложение
./.venv/Scripts/python.exe main.py
```

### Сборка EXE и установщика

```powershell
# Собрать приложение и portable ZIP
./scripts/build-windows.ps1

# Подготовить Inno Setup и собрать установщик
./scripts/install-inno.ps1
./scripts/make-installer.ps1
```

Результаты появятся в `dist/`. Версия задаётся в `src/al_media/__init__.py`; EXE, установщик и имена архивов получают её оттуда.

Логотип хранится в `assets/app.png`. При сборке `scripts/make-icon.py` создаёт из него Windows ICO с размерами от 16 до 256 пикселей. Пробные варианты дизайна не входят в дистрибутив.

### Структура проекта

```text
al-media/
├── src/al_media/          # Код приложения
│   ├── app.py            # Запуск и идентификация приложения
│   ├── core/             # yt-dlp, очередь, форматы и обработка ошибок
│   ├── ui/               # Окна, карточки загрузок и темы
│   ├── i18n/             # RU / EN / UK
│   ├── config.py         # Настройки и каталоги данных
│   └── database.py       # История и состояние очереди в SQLite
├── assets/               # Логотип и ресурсы интерфейса
├── packaging/            # PyInstaller и Inno Setup
├── scripts/              # Подготовка окружения и сборка
├── tools/                # Манифест инструментов и уведомления о лицензиях
├── docs/                 # Инструкции и скриншоты
├── tests/                # Регрессионные проверки
├── .github/workflows/    # Сценарий CI с ручным запуском
├── main.py               # Точка входа
├── pyproject.toml        # Python-пакет
└── requirements-build.txt
```

`.venv/`, `build/`, `dist/`, локальные данные и EXE инструментов исключены из Git. Для пользователей публикуйте Setup и ZIP как файлы релиза; исходный репозиторий остаётся небольшим.

## Зависимости

- [PySide6 / Qt](https://doc.qt.io/qtforpython-6/) — интерфейс.
- [yt-dlp](https://github.com/yt-dlp/yt-dlp) — получение информации и загрузка медиа.
- [FFmpeg](https://ffmpeg.org/) — объединение видео со звуком и конвертация аудио.
- [Deno](https://deno.com/) — JavaScript runtime для обработчиков yt-dlp.
- [PyInstaller](https://pyinstaller.org/) и [Inno Setup](https://jrsoftware.org/isinfo.php) — сборка Windows-дистрибутива.
