## Возможности

- **Анализ ссылки** — название, автор, крупное превью, длительность и примерный размер, когда источник предоставляет эти данные.
- **Качество источника** — максимум и доступные меньшие разрешения определяются автоматически, включая 4K и 8K.
- **Видео или аудио** — исходный аудиопоток, M4A при наличии и MP3. По умолчанию MP3 — 320 кбит/с; готовый MP3 меньшего битрейта не увеличивается искусственно.
- **Очередь под кнопкой скачивания** — отдельный прогресс каждого файла, три одновременные загрузки по умолчанию и автоматический запуск ожидающих.
- **Скачанные файлы** — сохраняемый список без дублирования прогресса, с форматом, размером и кнопками открытия файла и папки.
- **Списки и плейлисты** — несколько ссылок с новой строки, перетаскивание `.txt`, выбор элементов плейлиста.
- **Дополнительные параметры** — временной фрагмент, звуковая дорожка и субтитры, если они доступны у источника.
- **Музыка** — теги и обложки, варианты имён и подпапки по сайту, автору или плейлисту.
- **Оформление** — боковая навигация, тёмная, светлая и системная темы; English, Русский, Беларуская, Українська.
- **Фоновая работа** — настройка закрытия в трей и уведомление по завершении очереди.
- **Инструменты в комплекте** — yt-dlp, FFmpeg/FFprobe и Deno. Для готовой сборки отдельно устанавливать Python не нужно.

Поддержка сайтов обеспечивается [yt-dlp](https://github.com/yt-dlp/yt-dlp): YouTube, Facebook, Instagram, TikTok, SoundCloud, X (Twitter) и другие площадки из [списка обработчиков](https://github.com/yt-dlp/yt-dlp/blob/master/supportedsites.md). Доступность зависит от сайта, конкретного материала и подключения.

## Установка

Готовые сборки распространяются через раздел **Releases** этого репозитория.

| Файл | Назначение |
|---|---|
| `ALMedia-<версия>-Setup-win-x64.exe` | Установить приложение для текущего пользователя |
| `ALMedia-<версия>-portable-win-x64.zip` | Запустить без установщика после полной распаковки архива |
| `SHA256SUMS.txt` | Контрольные суммы файлов выпуска |

**Требования:** Windows 10 или 11, 64-разрядная система, интернет и свободное место для загружаемых файлов.

В portable-папке запускайте `ALMedia.exe`. Сохраняйте рядом с ним все поставляемые папки — в них находятся компоненты приложения.

Новую версию можно установить поверх предыдущей. Удалить приложение можно через **Параметры Windows → Приложения → AL Media**. Скачанные файлы при удалении программы сохраняются.

## Использование

1. Вставьте ссылку на странице **Загрузки**. Анализ начнётся автоматически.
2. Выберите **Видео** или **Аудио**, затем качество или формат.
3. Нажмите **Скачать**. После завершения доступны **Открыть файл** и **Показать в папке**.

По умолчанию используется папка Windows «Загрузки». Её можно изменить в **Настройках**.

### Другое качество или только аудио

После анализа рядом с переключателем **Видео / Аудио** появляются параметры источника. Переключение на **Аудио** позволяет получить звук из видео. Последний выбор запоминается.

Список разрешений формируется по доступным форматам ролика. Приложение не превращает исходное 720p-видео в 1080p. Битрейт MP3 задаёт параметры конвертации и не улучшает исходную запись.

### Несколько ссылок

Вставьте ссылки с новой строки или перетащите `.txt`, затем нажмите **Скачать**. Программа проанализирует ссылки и запустит загрузки. По умолчанию одновременно обрабатываются три файла; остальные ожидают свободного места. Пока очередь работает, можно добавлять новые ссылки. Для плейлиста откроется выбор элементов. Повторные ссылки в одном списке пропускаются.

В блоке **Фрагмент и дорожки** нажмите **Настроить**, чтобы открыть выпадающую панель, затем **Применить**. Для аудио доступна только обрезка; для видео — также звуковая дорожка и субтитры. Панель не сдвигает кнопку скачивания. В **Настройках** доступны имена файлов, подпапки, одновременные загрузки и музыкальные метаданные.

До вставки ссылки отображается подсказка, во время анализа — загрузочный макет. Параметры и кнопка **Скачать** появляются после анализа. Компактная форма помещается без прокрутки при размере окна от 960 × 640; список загрузок при необходимости прокручивается. Ссылка остаётся после скачивания, чтобы можно было выбрать другой формат или фрагмент. Приложение запускается развёрнутым.

При объединении исходных потоков загрузчик может использовать MKV. До получения файла карточка показывает «Видео» и качество; после завершения — фактическое расширение MP4, MKV или другого контейнера.

Большое превью показывает выбранную запись. Слайд-шоу использует до восьми кадров из доступного видео с интервалом три секунды. Для сетевых кадров требуется поддержка HTTP Range и дополнительный трафик; иначе остаётся обложка. Извлечение и анимация приостанавливаются при скрытии окна. Параметры записи можно изменить до загрузки, выбрав её в списке. Готовые файлы получают обычные имена; совпадения нумеруются `(2)`, `(3)`.

## Если видео не скачивается

AL Media работает с общедоступными материалами без входа в браузер и не читает браузерные cookies. Автоматических проверок обновлений нет.

- **HTTP 429 / проверка на бота:** сайт ограничил запросы с текущего подключения. Попробуйте позже или через другую сеть.
- **Видео требует входа, закрыто или недоступно в регионе:** приложение не обходит эти ограничения.
- **Ссылка не поддерживается:** проверьте ссылку и наличие поддержки площадки в yt-dlp. Изменения на сайте могут временно нарушить загрузку.
- **Не найдены компоненты:** распакуйте portable-архив целиком или переустановите приложение из полного установщика.

Технические журналы сохраняются в каталоге данных приложения. Переустановка сама по себе не снимает ограничения сайта.

## Разработка

Для запуска из исходников и сборки нужны **Windows x64, Python 3.12 и PowerShell**. Команды выполняются из корня клонированного репозитория.

```powershell
# Создать окружение и установить закреплённые зависимости
./scripts/bootstrap.ps1

# Получить yt-dlp, FFmpeg/FFprobe и Deno с проверкой SHA-256
./scripts/fetch-tools.ps1

# Запустить приложение
./.venv/Scripts/python.exe main.py
```

### Сборка EXE и установщика

```powershell
# Собрать приложение и portable ZIP
./scripts/build-windows.ps1

# Подготовить Inno Setup и собрать установщик
./scripts/install-inno.ps1
./scripts/make-installer.ps1
```

Результаты появятся в `dist/`. Версия задаётся в `src/al_media/__init__.py`; EXE, установщик и имена архивов получают её оттуда.

Логотип хранится в `assets/app.png`. При сборке `scripts/make-icon.py` создаёт из него Windows ICO с размерами от 16 до 256 пикселей. Пробные варианты дизайна не входят в дистрибутив.

### Структура проекта

```text
al-media/
├── src/al_media/          # Код приложения
│   ├── app.py            # Запуск и идентификация приложения
│   ├── core/             # yt-dlp, очередь, форматы и обработка ошибок
│   ├── ui/               # Окна, карточки загрузок и темы
│   ├── i18n/             # EN / RU / BE / UK
│   ├── config.py         # Настройки и каталоги данных
│   └── database.py       # Список загрузок и состояние очереди в SQLite
├── assets/               # Логотип и ресурсы интерфейса
├── packaging/            # PyInstaller и Inno Setup
├── scripts/              # Подготовка окружения и сборка
├── tools/                # Манифест инструментов и уведомления о лицензиях
├── docs/                 # Инструкции и скриншоты
├── tests/                # Регрессионные проверки
├── .github/workflows/    # Сценарий CI с ручным запуском
├── main.py               # Точка входа
├── pyproject.toml        # Python-пакет
└── requirements-build.txt
```

`.venv/`, `build/`, `dist/`, локальные данные и EXE инструментов исключены из Git. Для пользователей публикуйте Setup и ZIP как файлы релиза; исходный репозиторий остаётся небольшим.

## Зависимости

- [PySide6 / Qt](https://doc.qt.io/qtforpython-6/) — интерфейс.
- [yt-dlp](https://github.com/yt-dlp/yt-dlp) — получение информации и загрузка медиа.
- [FFmpeg](https://ffmpeg.org/) — объединение видео со звуком и конвертация аудио.
- [Deno](https://deno.com/) — JavaScript runtime для обработчиков yt-dlp.
- [PyInstaller](https://pyinstaller.org/) и [Inno Setup](https://jrsoftware.org/isinfo.php) — сборка Windows-дистрибутива.
