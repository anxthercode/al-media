AL Media 0.5.0 обновляет интерфейс и работу с видео и аудио.

- Компактный интерфейс с боковой навигацией, тёмной и светлой темами, четырьмя языками.
- Предпросмотр источника; вертикальное изображение сохраняет пропорции и дополняется размытым фоном.
- Подсказка до вставки ссылки и отдельное состояние анализа. Параметры появляются после получения данных.
- Качество по доступным потокам источника; исходное аудио, M4A и MP3 320/192/128.
- Выпадающая панель обрезки, звуковой дорожки и субтитров. Для аудио доступна обрезка.
- Ссылка и настройки остаются после скачивания; повторная загрузка создаёт отдельное задание.
- Очередь с отдельным прогрессом каждого файла, отменой и автоматическим запуском ожидающих задач.
- Сохраняемый список скачанных файлов, читаемые имена, открытие файла и папки.
- Резервное определение длительности Reels через FFprobe и оценка размера по битрейту.
- Улучшены отрисовка текста, масштабирование Windows, отступы и переключение видео/аудио.

Windows 10/11 x64. yt-dlp, FFmpeg/FFprobe и Deno включены в сборку.

Для установки скачайте **ALMedia-0.5.0-Setup-win-x64.exe**. Для запуска без установки полностью распакуйте **ALMedia-0.5.0-portable-win-x64.zip** и запустите **ALMedia.exe**. Сохраняйте рядом все папки из архива.

При обновлении с 0.4.0 можно установить новую версию поверх предыдущей. Профиль и скачанные файлы сохраняются.
