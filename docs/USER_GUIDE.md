# AL Media

Полное название приложения — **AnyLoad Media**.

Вставьте ссылку и нажмите **Скачать** или Enter. Приложение выберет лучшее доступное видео со звуком и сохранит его в папку «Загрузки».

Для другого разрешения или MP3 вставьте ссылку и нажмите **Качество…**. После получения информации выберите вариант в карточке и нажмите **Начать**. Разрешения берутся из самого видео.

## Установка и переустановка

- `ALMedia-<версия>-Setup-win-x64.exe` — установщик для Windows 10/11 x64. Python отдельно не требуется.
- Уже установленную версию обычно можно заменить запуском нового установщика; удалять её предварительно не обязательно.
- Удаление: «Параметры Windows → Приложения → AL Media» или `unins000.exe` в папке установки.
- После удаления можно запустить установщик заново. Скачанные видео, история и пользовательские настройки сохраняются; это не полный сброс данных.
- `ALMedia.exe` — запуск приложения, а не установка. Для portable-версии сначала распакуйте ZIP целиком. Папки `tools`, `assets` и `_runtime_v2` нужны для работы.

## Что ещё доступно

**Папка** открывает каталог загрузок. **История** содержит завершённые задачи. Настройки позволяют изменить папку, тему и язык. Несколько ссылок можно вставить с новой строки. Остановка не удаляет уже скачанные файлы.

Приложение не обращается к браузерному профилю, не требует cookies и не проверяет обновления. yt-dlp, Deno и FFmpeg входят в комплект.

## Если сайт не отдаёт видео

Поддерживаются общедоступные материалы, которые сайт разрешает получить без входа. Закрытые, платные, возрастные и региональные ограничения могут помешать загрузке.

«HTTP 429 / проверка на бота» означает, что YouTube отклонил запрос с текущего подключения. Попробуйте позже или через другую сеть. Переустановка и повторное нажатие кнопки не гарантируют снятия ограничения. Не требуется искать отсутствующий yt-dlp: он поставляется вместе с приложением.

Подробности технических ошибок сохраняются в виде безопасных кодов: **О программе → Открыть папку логов**. При новой установке история и журналы находятся в `%LOCALAPPDATA%/ALMedia`, настройки — в профиле Windows. При переходе с прежнего названия приложение продолжает использовать существующий профиль, чтобы сохранить историю и настройки. Удаление программы не удаляет ваши загрузки.
