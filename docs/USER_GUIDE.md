# AL Media 0.5.0

AL Media (AnyLoad Media) скачивает общедоступные видео и аудио через yt-dlp.

## Загрузка

Приложение запускается развёрнутым. Вставьте ссылку в однострочное поле на странице **Загрузки**. До вставки ссылки показывается подсказка, во время автоматического анализа — загрузочный макет. После анализа выберите **Видео** или **Аудио**, качество и нажмите **Скачать**. Ссылка и настройки останутся в форме для следующей загрузки.

Разрешения берутся из доступных потоков: если максимум 480p, первым будет 480p; если 2160p — 2160p. Искусственного повышения разрешения нет. **Аудио** извлекает звук из видео или скачивает самостоятельную аудиозапись.

Доступны исходный аудиопоток, M4A при наличии и MP3 320/192/128 кбит/с. По умолчанию MP3 — 320. Готовый MP3 меньшего битрейта сохраняется без увеличения; после завершения карточка показывает фактический битрейт. Перекодирование не восстанавливает потерянные детали записи.

Кнопка **Настроить** открывает выпадающую панель без смещения нижних элементов. Для аудио доступна только обрезка; для видео — обрезка, дорожка и субтитры. Изменения сохраняются кнопкой **Применить**. Escape и щелчок снаружи закрывают панель. Время: секунды, `мм:сс` или `чч:мм:сс`. В списке субтитров вариант **SRT** сохраняет отдельный файл, а **Встроить** добавляет дорожку в MKV. У фрагментов время субтитров сдвигается к началу фрагмента.

Для объединения видео и аудио может использоваться MKV. До завершения карточка показывает «Видео» и выбранное качество, после — фактический формат файла. Боковые поля вертикального предпросмотра заполняются размытым затемнённым изображением.

Если сайт не сообщает длительность, приложение дополнительно запрашивает служебные данные прямого потока через FFprobe. Длительность и примерный размер могут появиться чуть позже обложки. Если готовый размер неизвестен, оценка использует длительность и битрейт выбранного качества. При недоступности этих данных остаётся «—».

Большое превью справа показывает источник или выбранную запись списка. В узком окне оно располагается под параметрами. Для видео приложение может получить до восьми кадров из локального файла или доступного сетевого потока и показывать их каждые три секунды. Это требует дополнительного трафика; сервер должен поддерживать переход к нужной части файла. Если подходящих кадров нет, остаётся качественная обложка. При скрытии окна извлечение кадров и анимация останавливаются. Предпросмотр не повышает разрешение исходника.

## Список и плейлисты

Вставьте несколько ссылок по одной на строку или перетащите `.txt` и нажмите **Скачать**. Анализ и загрузка начнутся автоматически. Для плейлиста выберите элементы в открывшемся окне.

Под кнопкой находится **Очередь загрузок**. У каждого файла свой индикатор на всю ширину блока, процент, скорость, оставшееся время и отмена. По умолчанию загружаются три файла одновременно; ожидающие запускаются автоматически. Следующую ссылку можно вставить, пока очередь работает. Выбор формата новой ссылки не меняет параметры уже добавленных задач.

Список сохраняется между запусками. Удаление карточки и очистка завершённых записей не удаляют файлы. Прерванную загрузку можно продолжить; докачивание зависит от сервера. При повторе можно открыть существующий файл или скачать заново.

После всей обработки запись переходит в **Скачанные файлы**. Здесь показаны имя файла, формат, качество или фактический битрейт и размер; повторного индикатора и статуса «Готово» нет. **Открыть файл** запускает файл, **Показать в папке** выделяет его в Проводнике. Контекстное меню позволяет убрать запись из списка. Папка сохранения меняется в настройках.

## Настройки и фоновая работа

В **Настройках** меняются папка, тема и язык. Языки: English, Русский, Беларуская, Українська. Темы: системная, тёмная и светлая.

В разделе **Загрузка и сохранение** доступны одновременные загрузки (три по умолчанию, от одной до пяти), имя «Название» или «Исполнитель — название», подпапки по сайту/автору/плейлисту, музыкальные теги и обложки. Готовые файлы сохраняются с обычными именами; совпадения нумеруются без перезаписи. Параметры сохраняются при изменении.

Галочка **Сворачивать в область уведомлений при закрытии окна** оставляет очередь работать в фоне после нажатия крестика. Без галочки крестик закрывает приложение; при активной загрузке появится подтверждение остановки. Команда **Выйти** в меню значка всегда завершает программу. По завершении фоновой очереди приходит одно уведомление.

**О программе** содержит описание приложения, версию, поддерживаемые ресурсы, авторство и лицензии.

## Установка и переустановка

- `ALMedia-<версия>-Setup-win-x64.exe` — установщик для Windows 10/11 x64. Python отдельно не требуется.
- Уже установленную версию обычно можно заменить запуском нового установщика; удалять её предварительно не обязательно.
- Удаление: «Параметры Windows → Приложения → AL Media» или `unins000.exe` в папке установки.
- После удаления можно запустить установщик заново. Скачанные видео, список загрузок и пользовательские настройки сохраняются; это не полный сброс данных.
- `ALMedia.exe` — запуск приложения, а не установка. Для portable-версии сначала распакуйте ZIP целиком. Папки `tools`, `assets` и `_runtime_v2` нужны для работы.

Приложение не обращается к браузерному профилю, не читает cookies и не проверяет обновления. yt-dlp, Deno и FFmpeg входят в комплект.

## Если сайт не отдаёт видео

Поддерживаются общедоступные материалы, которые сайт разрешает получить без входа. Закрытые, платные, возрастные и региональные ограничения могут помешать загрузке.

«HTTP 429 / проверка на бота» означает, что YouTube отклонил запрос с текущего подключения. Попробуйте позже или через другую сеть. Переустановка и повторное нажатие кнопки не гарантируют снятия ограничения. Не требуется искать отсутствующий yt-dlp: он поставляется вместе с приложением.

Технические журналы сохраняются в каталоге данных приложения. При новой установке список и журналы находятся в `%LOCALAPPDATA%/ALMedia`, настройки — в профиле Windows. При переходе с прежнего названия сохраняется существующий профиль. Удаление программы не удаляет ваши загрузки.
