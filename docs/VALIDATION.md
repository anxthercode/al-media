# Проверка AL Media 0.5.0

Проверено 19 октября 2026 года на Windows x64, Python 3.12.10 / PySide6 6.12.

## Автоматические проверки

- Полный набор: 90 тестов. Ruff без ошибок.
- Отдельно при масштабе 150%: 39 проверок интерфейса, предпросмотра и резервного анализа.
- Проверены очередь, независимые параметры загрузок, имена файлов, история, MP3, субтитры, фрагменты и отмена устаревших запросов.
- Проверены пустая форма, анализ, ошибка, очистка ссылки и повторная загрузка с другим форматом.
- Основная форма без очереди помещается при 960 × 640, 1280 × 720, 1536 × 864 и 1920 × 1080.
- Проверены открытие и применение параметров, неверный диапазон, Escape с отменой правок, вложенный список субтитров и сохранение положения кнопки.

## Интерфейс

Фон проверен по верхней и нижней части контрольного кадра: обе остаются в размытой подложке. Основное изображение сохраняет резкость и пропорции. Проверены отступ 20 px перед скачиванием, размещение поля папки и кнопки изменения, нижнее положение авторства.

Снимки в `docs/images/` используют искусственные данные и обновляются сценарием `scripts/capture-ui.py`. Каждый запуск использует отдельную базу в памяти и не накапливает тестовые карточки.

## Проверка Reels

На публичном Reels из пользовательского примера подтверждено отсутствие длительности в JSON yt-dlp. Резервный запрос дал 31,09 с; интерфейс показал 0:31, ≈ 5,6 МБ для видео и ≈ 1,2 МБ для MP3 320. Два состояния проверены на реальной обложке; снимки сохранены локально в `.tmp/reel-review/`.

Уточнение данных не сбрасывает несохранённые поля открытой панели. При отказе сервера либо отсутствии служебных данных значение остаётся неизвестным.

## Сборка и границы проверки

Версия приложения, EXE, установщика и portable ZIP — 0.5.0. Файлы текущего выпуска перечислены в `dist/SHA256SUMS.txt`. Промежуточные локальные сборки не являются отдельными публичными релизами.

EXE прошёл проверочный запуск на временном профиле. У portable ZIP проверены обязательные файлы, версия руководства и CRC. Установщик собран; его версия и SHA-256 обоих файлов релиза проверены. Установка поверх пользовательского приложения автоматически не выполнялась.

Комплектные yt-dlp / FFmpeg / FFprobe проверяются на локальном видео через `scripts/local-engine-smoke.py`: анализ, видео, MP3, проверка потоков и сохранение истории. Проверочный запуск EXE использует отдельный временный профиль.

Чистая установка на другом компьютере, системные уведомления и загрузки на разных пользовательских подключениях требуют отдельной приёмки. Сборка установщика не означает его установки поверх пользовательского приложения.
