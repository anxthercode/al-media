# Устройство проекта

| Каталог / файл | Назначение |
|---|---|
| `src/al_media/` | Исходный Python-пакет приложения |
| `core/` внутри пакета | Команда yt-dlp, процесс загрузки, очередь, форматы, ошибки |
| `ui/` внутри пакета | Главное окно, карточки и оформление |
| `i18n/` внутри пакета | Русский, английский и украинский интерфейс |
| `assets/` | Выбранный логотип `app.png`, многоразмерный `app.ico` и SVG интерфейса |
| `tools/` | Закреплённые yt-dlp, Deno, FFmpeg/FFprobe, manifest и лицензии |
| `packaging/` | PyInstaller и Inno Setup |
| `scripts/` | Подготовка окружения, сборка и служебные сценарии |
| `tests/` | Существующие регрессионные проверки; не входят в готовое приложение |
| `docs/` | Инструкция, заметки о релизе, история проектирования |
| `.github/workflows/` | Сборка CI с ручным запуском |
| `build/` | Генерируемые промежуточные файлы и локальный компилятор установщика |
| `dist/` | Готовые файлы для передачи пользователю |
| `.venv/` | Изолированное окружение разработчика, не часть дистрибутива |
| `.tmp/` | Только временные материалы диагностики; не часть дистрибутива |

`src`-layout и имена Python-модулей стандартны. Переименование корневой папки `Best Media Downloader` ради внешнего вида не нужно: оно нарушит пути существующего окружения. Публичный репозиторий можно назвать `al-media`; рабочую копию лучше создать заново в каталоге с новым именем и повторить bootstrap, а не переносить `.venv`.

Не удаляйте `tools/` и файлы portable-пакета выборочно: они используются приложением. Внешнему пользователю не нужны исходники, тесты, компилятор и `.venv` — передаётся только Setup или portable ZIP из `dist/`.

## Данные пользователя

Новая установка хранит историю/логи в `%LOCALAPPDATA%/ALMedia`, настройки через QSettings в `HKEY_CURRENT_USER/Software/AnyLoadMedia/ALMedia`. Для portable-профиля создайте пустой `portable.flag` рядом с EXE до первого запуска; данные будут в соседней `data/`. Не включайте `portable.flag` и `data/` в публикуемый пакет с чужими данными.

При переустановке база сохраняется. Неиспользуемые старые параметры cookies остаются в хранилище Windows, но новая версия их не читает и не применяет. Их наличие не включает доступ к браузеру.

При наличии профиля прежних версий используется существующий каталог `%LOCALAPPDATA%/UniversalMediaStudio` и прежнее хранилище QSettings. Это совместимость данных, а не старое название продукта. AppId установщика тоже сохранён: новый Setup обновляет существующую установку и убирает прежний EXE и ярлыки. Сохранённый путь установки может остаться прежним.

## Идентификация и ресурсы

Короткое имя **AL Media**, полное **AnyLoad Media** и Windows AppUserModelID определены в `src/al_media/__init__.py`. Полное имя показано на странице «О программе» и в свойствах EXE.

`scripts/make-icon.py` формирует ICO из `assets/app.png` без перерисовки эмблемы. В PyInstaller задан явный список ресурсов: PNG/ICO и используемые SVG. Локальные эскизы и промпты исключены через `.gitignore` и в готовую сборку не входят.
