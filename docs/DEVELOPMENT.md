# Устройство проекта

| Каталог / файл | Назначение |
|---|---|
| `src/al_media/` | Исходный Python-пакет приложения |
| `core/` внутри пакета | Команда yt-dlp, процесс загрузки, очередь, форматы, ошибки |
| `ui/` внутри пакета | Главное окно, карточки и оформление |
| `i18n/` внутри пакета | English, Русский, Беларуская, Українська |
| `assets/` | Выбранный логотип `app.png`, многоразмерный `app.ico` и SVG интерфейса |
| `tools/` | Закреплённые yt-dlp, Deno, FFmpeg/FFprobe, manifest и лицензии |
| `packaging/` | PyInstaller и Inno Setup |
| `scripts/` | Подготовка окружения, сборка и служебные сценарии |
| `tests/` | Существующие регрессионные проверки; не входят в готовое приложение |
| `docs/` | Инструкция, заметки о релизе, история проектирования |
| `.github/workflows/` | Сборка CI с ручным запуском |
| `build/` | Генерируемые промежуточные файлы и локальный компилятор установщика |
| `dist/` | Готовые файлы для передачи пользователю |
| `.venv/` | Изолированное окружение разработчика, не часть дистрибутива |
| `.tmp/` | Только временные материалы диагностики; не часть дистрибутива |

`src`-layout и имена Python-модулей стандартны. Переименование корневой папки `Best Media Downloader` ради внешнего вида не нужно: оно нарушит пути существующего окружения. Публичный репозиторий можно назвать `al-media`; рабочую копию лучше создать заново в каталоге с новым именем и повторить bootstrap, а не переносить `.venv`.

Не удаляйте `tools/` и файлы portable-пакета выборочно: они используются приложением. Внешнему пользователю не нужны исходники, тесты, компилятор и `.venv` — передаётся только Setup или portable ZIP из `dist/`.

## Данные пользователя

Новая установка хранит историю/логи в `%LOCALAPPDATA%/ALMedia`, настройки через QSettings в `HKEY_CURRENT_USER/Software/AnyLoadMedia/ALMedia`. Для portable-профиля создайте пустой `portable.flag` рядом с EXE до первого запуска; данные будут в соседней `data/`. Не включайте `portable.flag` и `data/` в публикуемый пакет с чужими данными.

При переустановке база сохраняется. Неиспользуемые старые параметры cookies остаются в хранилище Windows, но новая версия их не читает и не применяет. Их наличие не включает доступ к браузеру.

При наличии профиля прежних версий используется существующий каталог `%LOCALAPPDATA%/UniversalMediaStudio` и прежнее хранилище QSettings. Это совместимость данных, а не старое название продукта. AppId установщика тоже сохранён: новый Setup обновляет существующую установку и убирает прежний EXE и ярлыки. Сохранённый путь установки может остаться прежним.

## Идентификация и ресурсы

Короткое имя **AL Media**, полное **AnyLoad Media** и Windows AppUserModelID определены в `src/al_media/__init__.py`. Полное имя показано на странице «О программе» и в свойствах EXE.

`scripts/make-icon.py` формирует ICO из `assets/app.png` без перерисовки эмблемы. В PyInstaller задан явный список ресурсов: PNG/ICO и используемые SVG. Локальные эскизы и промпты исключены через `.gitignore` и в готовую сборку не входят.

## Новые модули и проверки

`core/metadata.py` формирует качества и дорожки по JSON источника. `naming.py` задаёт безопасные стабильные пути и сравнивает повторы. `commands.py` строит аргументы без shell. `engine.py` управляет асинхронными процессами; `postprocess.py` сдвигает SRT и планирует FFmpeg/FFprobe. `scheduler.py` сохраняет очередь в SQLite.

`ui/composer.py` задаёт форму загрузки, отдельные области очереди и скачанных файлов. `composer_options.py` содержит редактор фрагмента, дорожки и субтитров; `task_options.py` — общую валидацию этих параметров и выбор плейлиста. `selection.py` содержит выбор формата, `widgets.py` — единый переключатель и SVG-компоненты, `pages.py` — настройки и сведения о ресурсах. Переводы интерфейса — `i18n/desktop.py`.

Форма использует состояния подсказки, анализа и готового источника. Параметры открываются через `OptionsPopup` без места в основном layout; применение записывает параметры в черновик, закрытие отменяет незаписанные правки. При отправке черновика в очередь создаётся отдельный идентификатор задания. `packaging/ALMedia.manifest` задаёт DPI для каждого монитора; `app.py` настраивает шрифт Segoe UI с хинтингом.

`core/source_probe.py` асинхронно уточняет отсутствующую длительность и размер через FFprobe. Он ограничивает число запросов, время и служебный вывод; смена ссылки отменяет запрос. Обновление фактов источника не пересоздаёт редактор параметров. `ui/media_preview.py` размывает весь кадр в подложке через Qt, сохраняя исходное изображение поверх неё.

```powershell
$env:QT_QPA_PLATFORM = 'offscreen'
./.venv/Scripts/python.exe -m pytest -q
./.venv/Scripts/python.exe -m ruff check src tests scripts/capture-ui.py scripts/feature-smoke.py scripts/frame-smoke.py scripts/preview-smoke.py scripts/local_engine_smoke_helpers.py
./.venv/Scripts/python.exe scripts/capture-ui.py
./.venv/Scripts/python.exe scripts/feature-smoke.py
./scripts/smoke-test.ps1
```

`feature-smoke.py` создаёт локальные медиа и HTTP-сервер loopback и проверяет настоящие yt-dlp/FFmpeg/FFprobe: три сценария MP3, точную обрезку, отдельные и встроенные субтитры, теги и обложку. `smoke-test.ps1` проверяет упакованную программу. `--smoke-gui` использует временный профиль и не открывает пользовательскую базу.

`ui/media_preview.py` управляет асинхронной загрузкой изображений, ограниченным кэшем и рендерингом кадров. `ui/preview_frames.py` извлекает до восьми кадров одним процессом FFmpeg за раз, сначала проверяет HTTP Range, ограничивает размеры кадра и память, прекращает работу при скрытии окна. `scripts/frame-smoke.py` проверяет настоящий HTTP Range и FFmpeg, паузу/продолжение, кэш и отказ от сканирования при ответе 200. `scripts/preview-smoke.py` проверяет HTTP-загрузку большого спрайта, повторное использование кэша и остановку анимации. `core/naming.py:publish_files` переименовывает готовое медиа и связанные субтитры после всей обработки, сохраняя имена частей для докачивания.
