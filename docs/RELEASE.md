# Подготовка публичного выпуска

## Что подготовлено

Установщик для текущего пользователя без требования администратора; portable ZIP; единый источник версии; метаданные версии и значок EXE; SHA-256 для файлов релиза; отдельное хранение данных пользователя; фиксированные версии инструментов; изолированное окружение сборки. Повторный запуск не создаёт вторую очередь в том же профиле.

## Что ещё необходимо до объявления production-ready

1. Подтвердить целевой сценарий YouTube на реальных пользовательских подключениях. На текущем подключении диагностика получила 429 / проверку на бота. Нельзя обещать «скачивает любое видео» или считать переустановку решением этой ошибки.
2. Выполнить приёмку на чистой Windows, включая установку, переустановку, отмену/возобновление и загрузки разных площадок. В текущем цикле по просьбе пользователя тесты не запускались. Автоматизация в `tests/` и CI сохранена для будущего использования.
3. Подписать EXE и Setup сертификатом издателя с timestamp ([Microsoft SignTool](https://learn.microsoft.com/en-us/windows/win32/seccrypto/signtool)). Сертификат и проверенная личность издателя здесь не предоставлены; текущие файлы не подписаны. После подписи заново сформировать SHA256SUMS. SHA-256 проверяет целостность, но не заменяет подпись издателя.
4. Завершить аудит условий распространения точных сборок Qt/PySide, FFmpeg и других включённых компонентов: полные тексты лицензий, уведомления, соответствующий исходный код/предусмотренный лицензией способ его получения. Список в `THIRD_PARTY_NOTICES.md` сам по себе не подтверждает выполнение всех условий.
5. Для коммерческого выпуска отдельно согласовать условия компилятора установщика: текущий Inno Setup выводит «Non-commercial use only», а [официальная страница](https://jrsoftware.org/isinfo.php) предлагает коммерческим пользователям приобрести лицензию. Публичный выпуск и коммерческое использование — не одно и то же.
6. Указать собственный канал поддержки, страницу загрузки, журнал изменений и поддерживаемые версии Windows. Не использовать репозиторий вдохновения как официальный адрес поддержки этого продукта.

Не включайте в релиз тестовые базы, журналы, cookies, пользовательские загрузки и исходники окружения. Готовые артефакты перечислены в `dist/SHA256SUMS.txt`. Автоматических проверок обновлений внутри приложения нет; обновление — запуск нового установщика.

## Решения по интерфейсу

Основное действие — «Скачать». Качество и MP3 — дополнительная ветка, которая не блокирует обычное скачивание. Настройки браузера и профессиональные параметры кодирования убраны. История и открытие папки оставлены: они помогают найти результат. Кнопки остановки и массового запуска показываются только когда есть соответствующие задачи. Ошибка сайта не должна маскироваться сообщением «yt-dlp не установлен».
